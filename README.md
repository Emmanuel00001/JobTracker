# Job Application Tracker
**Live Demo:** https://jobtracker-l77e.onrender.com
A full-stack web application to track job applications and their statuses.
## 🔍 What it does
- Add, edit and delete job applications
- Track application status: Applied, Interview, Offer, Rejected
- Dashboard with real-time stats
- Stores all data in a SQLite database
- Newest applications displayed first
## 🛠️ Built With
- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML, CSS
## ⚙️ How to Run
1. Clone the repository
git clone https://github.com/Emmanuel00001/JobTracker.git
2. Install dependencies
pip install flask flask-sqlalchemy
3. Run the app
python app.py
4. Open your browser and go to
http://127.0.0.1:5000
